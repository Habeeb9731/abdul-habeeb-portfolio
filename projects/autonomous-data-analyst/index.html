Overview

The first hour with a new dataset is always the same. This workspace does it for you.

Before any real analysis, every dataset needs the same groundwork: checking types, missing values, duplicates, outliers and distributions. Autonomous Data Analyst automates that first pass and presents it as a readable workspace — overview, data quality, insights and charts.

Challenge & solution

What made it hard, and how I approached it.

The challenge

AI analysis you can actually trust

  • Language models are good at explaining data but can invent numbers.
  • Messy real-world files: mixed types, inconsistent categories, missing values.
  • Results had to be clear to people who don’t read raw statistics.
The solution

Deterministic numbers, readable findings

  • A FastAPI profiling engine computes every metric deterministically — the same file always gives the same report.
  • Issues are grouped by severity with the affected columns, so it is obvious what to fix first.
  • Findings and charts are generated from the computed profile, keeping explanations grounded in real values.
Key features

Built around what people actually need.

Data quality

A canonical quality score with detected issues — missing values, inconsistencies, outliers.

Insights

Evidence-backed findings, each linked to the columns and values behind it.

Charts

Distributions and category breakdowns chosen automatically from the dataset’s structure.

Responsive

The workspace adapts to smaller screens with a collapsible sidebar, so reports can be checked on the go.

  • Demo dataset works without uploading

How it works

Under the hood.

  • FrontendVite + React + TypeScript workspace, deployed on Cloudflare Pages.
  • Profiling enginePython / FastAPI service computing deterministic dataset profiles.
  • Production APIDeployed as a Cloudflare Python Worker; local development uses FastAPI behind a Vite proxy.
  • Demo modeA built-in demo dataset so visitors can explore without uploading anything.

Takeaway

What I learned.

Separating “compute” from “explain” was the key decision. Keeping every number deterministic and only using AI-style summaries on top of it made the tool far more trustworthy.
